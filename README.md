# A’ That and A’ That (2026 Adaptation)

A modern, inclusive "fork" of Robert Burns’ 1795 classic *Is There for Honest Poverty*.

## 🎯 Vision
This adaptation refactors the original Scots poem into a universal anthem. By shifting the language from gender-specific terms to essence-based terms (Soul, Folk, Heart), we extend Burns' revolutionary idea of "intrinsic worth" to all people and even non-human life.

## 🛠 Refactoring Notes
* **Inclusivity:** Replaced "Man" and "Brithers" with "Soul," "Everyone," and "Kindred."
* **Clarity:** Swapped archaic Scots prepositions like *aboon* for *above* to ensure the message is accessible to modern listeners.
* **Metric Stability:** All changes maintain the original 4/4 "march" rhythm, ensuring compatibility with the traditional tune *Lady McIntosh’s Reel*.

## 📚 Glossary (The Original "Source Code")
| Original Scots | Modern Refactor | Definition |
| :--- | :--- | :--- |
| **Gowd** | Gold | The essential value (gold). |
| **Hoddin grey** | Clothes a'frayed | Coarse, un-dyed wool worn by the poor. |
| **Birkie** | That guy | A conceited, social-climbing fellow. |
| **Coof** | Fool | A blockhead or person lacking sense. |
| **Aboon** | Above | Superior to or beyond the reach of. |
| **Mauna fa’** | Cannot buy | Must not try / cannot achieve. |
| **Bear the gree** | Be the way | To take the prize or win the day. |
